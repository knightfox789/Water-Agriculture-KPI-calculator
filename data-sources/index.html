Future CACP update pipeline

New CACP Report→Update Excel Master→Validate→Build JSON / GeoJSON→Redeploy

The front-end discovers available year, season, state and crop values from data rather than hard-coded dropdown lists. A GitHub Pages workflow template is included under deployment/pages.yml.example, but it is intentionally not activated yet.

Data rules

  • Unique master key: Reference Year + Basis Type + Season + State + Crop.
  • Do not silently replace missing state wage with an All-India wage.
  • Projected master rows retain projected yield; latest compatible Actual labour/wage may be used only in the calculation layer and must be disclosed.
  • GIS no-data is not zero.
