About this project

A practical, transparent calculation toolkit for water-security, agriculture, GIS and monitoring work.

Purpose & scope

This website connects field measurements, programme/control comparisons, CACP reference data and GIS-based state selection in one browser-based calculation toolkit.

  • Water measurement using field-appropriate methods
  • Demand-side water saving by scenario
  • Additional agricultural production including CEY methods
  • Additional farmer income through programme-control crop economics
  • Person-days using the consolidated CACP reference master
