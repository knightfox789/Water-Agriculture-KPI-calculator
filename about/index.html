Website principles

  • Transparent formulas
  • Raw source data separated from outputs
  • No-data shown explicitly
  • Client-side calculation; no user data server required
  • Future CACP upgrades without rewriting calculator UI
  • GIS integration through Leaflet + GeoJSON
